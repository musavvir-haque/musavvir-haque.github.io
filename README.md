# musavvir-haque.github.io

Personal academic portfolio of Musavvir Haque, live at https://musavvir-haque.github.io/

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The whole site (HTML, CSS and JS in one file) |
| `404.html` | Custom "page not found" page |
| `Musavvir_Haque_B.Sc_EEE.pdf` | Current CV, linked from the site |
| `photo.jpg` | Profile photo, also used for social-share previews |
| `favicon*`, `apple-touch-icon.png`, `android-chrome-*.png`, `site.webmanifest` | Site icons and web app manifest |
| `robots.txt`, `sitemap.xml` | Search engine crawling hints |
| `googlee2498ef61e1c22eb.html` | Google Search Console verification (keep) |

## Updating

Edit `index.html` and push to `main`; GitHub Pages republishes automatically. To update the CV, replace the PDF and keep the same filename so existing links keep working.
